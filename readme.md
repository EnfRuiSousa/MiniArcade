
# MiniArcade 🎮

A collection of five classic browser games developed using HTML, CSS and JavaScript.

This is a personal software development project created to practise frontend development, programming logic, DOM manipulation and interactive user interfaces.

## Games

- 🧠 **Memory Match** — Find matching pairs of cards.
- 🔢 **Sudoku** — Solve number puzzles with three difficulty levels.
- 🔤 **Hangman** — Guess the hidden word before running out of attempts.
- ⭕ **Tic-Tac-Toe** — Play against the computer.
- ✊ **Rock, Paper, Scissors** — Challenge the computer.

## Features

- Five games in one application
- Modern, responsive interface
- Interactive animations
- No external libraries required
- Works directly in a web browser

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## How to Run

**Option 1 — Play online**

Use the live demo link:

https://enfruisousa.github.io/MiniArcade/

**Option 2 — Run locally**

1. Download or clone the repository.
2. Open `index.html` in your browser.
3. Select a game and start playing.

No installation is required.
